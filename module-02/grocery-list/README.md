# Grocery Shopping List

This is a grocery shopping list made with HTML, CSS and JavaScript.

## Features

- Add an item
- Mark an item as bought
- Unmark an item
- Remove an item
- Shows the number of items

## Files

- `index.html` - The HTML for the page
- `styles.css` - The styles for the page
- `app.js` - The JavaScript for the app
- `README.md` - Project information

## How it works

The items are stored in an array in `app.js`.

When I add, remove, or mark an item as bought, the array is changed first. Then the `render()` function updates the page.

## How to run

Open `index.html` in a browser.
