# Addis Market — Week 2 Project

## How to open

Open `index.html` in a web browser.

## What it does

- Adds a shopping item with a name and ETB price.
- Validates that both fields are filled.
- Creates each item using `createElement` and `append`.
- Allows items to be marked as bought.
- Allows items to be deleted.
- Uses event delegation on the list.
- Shows a live total of all item prices.
- Uses DOM selection, manipulation, events, and event delegation.
