# Day 20 — Country Facts Page

## How to run

Open `index.html` in a web browser.

## API

This project uses the free REST Countries API:

https://restcountries.com/v3.1/name/{country}

## Features

- Searches for a country by name.
- Defaults to Ethiopia.
- Shows Loading while fetching.
- Shows capital.
- Shows population with commas.
- Shows region.
- Shows currencies.
- Shows the country flag.
- Handles network and HTTP errors.
- Uses async/await and try/catch.
- Uses createElement to render facts.
