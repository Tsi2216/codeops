# Bole Coffee House

A fictional Addis Ababa business profile card created for Day 13.

## CSS Techniques Used

- CSS custom properties with `:root`
- `var()` for reusable values
- Global `box-sizing: border-box`
- Google Fonts
- Box model
- Padding, margin, border, and border-radius
- Typography hierarchy
- HSL colors
- `:hover` pseudo-class
- `::before` pseudo-element
- CSS spacing variables
