# Habesha Eatery Menu Card

## Requirements

- Uses box-sizing: border-box
- Uses a base font-family and line-height
- Menu card has padding and a border
- Menu card has a gold top accent
- Colors use CSS variables
- Includes a hover state
- Uses ::before to add "ETB" before the price
- Uses :nth-child(even) for the ingredient list
