# Ethio Telecom Dashboard

A fictional Ethio Telecom-style account dashboard rebuilt for Day 14.

## Grid

CSS Grid is used for:

- Overall page skeleton
- Header
- Sidebar
- Main content
- Footer
- Responsive stat cards
- Responsive service cards

The page skeleton uses grid-template-areas.

## Flexbox

Flexbox is used for:

- Navbar
- Logo and navigation links
- Buttons and navigation alignment
- Service card content

## Responsive Design

A media query at 700px changes the page to a single-column layout.

## Other Techniques

- Sticky header
- Auto-fit responsive card grid
- Relative positioning
- Absolute "New" badge
- Flexbox card layout
